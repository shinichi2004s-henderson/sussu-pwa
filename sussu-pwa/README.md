# すっす（仮） PWA

iPhone向けの自分専用Todo管理Webアプリです。

## 実装済み

- 3ページ構成
  - 重要度×緊急度の4分割マトリックス
  - 年 / 月 / 週 / 日の予定管理
  - 月間カレンダー（実行予定・期限・日付未設定）
- 3ページとも同じTodoデータを使用
- カレンダーの日付選択、前月／翌月移動、日ごとの一覧・編集・完了
- Todoの追加・編集・削除
- 完了一覧、復元、一括削除
- 完了 / 削除後5秒間の「元に戻す」
- マトリックス内の並び替え・別象限へのドラッグ移動
- 優先順位カラーを16色から選択
- カテゴリーの追加・名前変更・16色から色変更・削除
- マトリックスの表示項目を保ったコンパクト表示
- 期限と実行日を別管理
- 予定時刻は任意
- 未入力の予定は「時間未定」に表示
- 6:00〜24:00の時間割（初期版は1時間単位）
- 予定時刻を開始から終了まで、1つの縦長の四角形で表示
- 今週やること
- 今週Todoを実行日に割り当て
- 年間目標・月間目標
- 目標とTodoの関連付け
- サブTodo
- 昨日の未完了Todo移動確認
- JSONバックアップ / 復元
- PWA / Service Worker / オフラインキャッシュ

## PCで起動する

PWA機能を正しく動作させるため、`index.html` を直接ダブルクリックするのではなく、
簡易Webサーバーから起動してください。

Pythonが入っている場合:

```bash
cd sussu-pwa
python -m http.server 8000
```

ブラウザで次を開きます。

```text
http://localhost:8000
```

## 以前の版から更新する（Windows）

1. 念のため、旧版の「設定 → データを書き出す」でバックアップを保存します。
2. このZIPを右クリックして「すべて展開」します。
3. 以前 `python -m http.server 8000` を起動したターミナルで `Ctrl+C` を押します。
4. 展開先の `sussu-pwa` フォルダを開き、アドレスバーに `cmd` と入力してEnterを押します。
5. `python -m http.server 8000` を入力してEnterを押します。Pythonコマンドが使えない場合は `py -m http.server 8000` を使います。
6. PCのブラウザで `http://localhost:8000` を開きます。以前の表示が残る場合は `Ctrl+F5` で再読み込みします。PWAの更新で古い画面が残る場合は、タブを閉じて同じURLを開き直してください。

**新しい時間割が表示されない場合**は、利用中のポート番号で `http://localhost:8000/update.html` または `http://localhost:8765/update.html` を開き、「最新版を開く」を押してください。保存済みTodoを保持したまま古い画面用のキャッシュを外します。更新後は画面上部に小さく `v6` と表示されます。更新確認ページ自体が開けない場合は、今回展開した `sussu-pwa` フォルダでサーバーを起動しているか確かめてください。

13:00〜17:00の予定は、上端が13:00、下端が17:00に合う縦長の四角形として表示します。重なる予定は横に並びます。四角形を押すとTodoを編集できます。

設定（⚙）から優先順位やカテゴリーの色を押すと16色を選べます。カテゴリー追加時も16色から選択できます。旧版と同じブラウザの `http://localhost:8000` で開けば、通常は保存済みのTodoをそのまま読み込めます。URLのホスト名やポート番号が変わると保存領域も変わります。

## カレンダーの使い方

画面下の「カレンダー」を開くと、実行日が決まっているTodoは予定時刻・Todo名、期限があるTodoは期限として月間表示されます。同じ日に実行日と期限が重なれば1件にまとめて表示します。日付を押すと下にその日の全件が表示され、Todo名から編集できます。月の左右ボタンで移動し、「今日」で戻ります。日付未設定のTodoは月間表示に配置できないため、下部の「日付未設定のTodo」に表示します。完了済みTodoはカレンダーに表示しません。

## iPhoneで使う

iPhoneから同じWebサーバーへアクセスできるように公開する必要があります。
本番利用時は HTTPS のWebホスティング（例: GitHub Pages 等）へ配置してください。

Safariで公開URLを開き、

1. 共有ボタン
2. 「ホーム画面に追加」

でホーム画面から起動できます。

## データ保存

初期版はブラウザの `localStorage` に保存します。

設定 → データ管理 → 「データを書き出す」でJSONバックアップを保存できます。

## 15分単位へ変更する場所

`app.js` の `buildTimeOptions()` が予定時刻の選択肢を作っています。
初期版では1時間単位ですが、将来ここを15分刻みに変更できます。

## 注意

iPhoneのブラウザデータを削除するとローカル保存データが消える可能性があるため、
定期的にJSONバックアップを取ってください。
